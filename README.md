# Kawerify Learn

Welcome to **Kawerify Learn**, a powerful, free, and interactive web education platform designed to make learning code accessible to everyone—from kids to professional developers. Branded and powered by **[kawerifytech.com](https://kawerifytech.com)**, Kawerify Learn integrates step-by-step programming lessons with a real-time code generator, terminal simulator, and interactive playground.

---

## 🚀 Core Features

### 1. Alison-Inspired Course Catalog
- **Interactive Catalog**: A complete educational dashboard showcasing 8 language paths (HTML/CSS, JavaScript, React, Python, C, C++, C#, PHP) with dynamic progress bars.
- **Dual Learning Modes**:
  - **👦 Kid Mode**: Replaces dry definitions with fun, real-world analogies (e.g., comparing C++ Inheritance to robot parents inheriting parts, or Python variables to labeled toy boxes).
  - **👨‍💻 Dev Mode**: Delivers comprehensive syntax definitions, standard documentation notes, and technical scopes.
- **Interactive Quizzes**: Pass multiple-choice review questions with custom mascot feedback animations and audio alerts.

### 2. Live Code Generator & Compiler Mappings
- Generate boilerplate templates dynamically (e.g. React counters, C++ sorting algorithms, C# LINQ queries, Python games).
- Tweak input parameters (like thresholds, user names, array sizes) and compile code templates in real-time.
- Send generated code directly to the playground with a single click.

### 3. Integrated Playground & Terminal CLI
- **Code Editor**: Clean, responsive syntax sandbox area supporting live editing.
- **Live Preview Window**: Executes HTML/CSS/JS programs instantly inside an iframe sandbox.
- **Simulated Terminal Console**: Simulates compiler execution outputs for backend languages (C, C++, C#, Python, PHP) with typing animations.
- **File Exporters**: Download files with correct extensions (e.g., `.jsx`, `.cs`, `.py`) or export full HTML pages.

### 4. Licenses Builder & Legal Documentation
- **11 Open-Source Licenses**: Customize and download popular agreements (MIT, Apache 2.0, GPLv3, BSD, CC BY 4.0, etc.) by adjusting copyright year and owner fields in real-time.
- **5 Pre-Packaged Legal Policies**: Fully formatted Privacy Policy, Terms of Service, Cookies Policy, GDPR compliance, and Disclaimers branded for your project.

### 5. Curated Resources Hub
- Search and filter direct links to official documentation (React.dev, Python.org, Microsoft Learn, cppreference) and freeCodeCamp video courses.

## 📦 Installation & Setup
Since the application runs entirely client-side, you do not need database setups or package compilation:
1. Clone the repository:
   ```bash
   git clone https://github.com/tonderaikawere/kawerify-learn.git
   ```
2. Open [`index.html`](index.html) directly in any modern web browser, or serve it locally using a static server:
   ```bash
   npx serve .
   ```
